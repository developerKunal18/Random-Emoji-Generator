# Random Emoji Generator 😀  

A fun and interactive **Random Emoji Generator** built with **HTML**, **CSS**, and **JavaScript**.  
Displays a new random emoji each time you click the button, complete with smooth animations and a colorful design.

## ✨ Features
- Generates random emojis from a predefined list  
- Smooth scaling and fade animations  
- Bright, responsive interface  
- Easy to expand with custom emoji sets  

## 🛠️ Built With
- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
